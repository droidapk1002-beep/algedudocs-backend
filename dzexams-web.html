🔴 Comptes MEGA — Sélectionnez le(s) compte(s) à utiliser

Chargement...
Configuration dans .env :
MEGA_EMAIL=compte1@email.com
MEGA_PASSWORD=motdepasse1
MEGA_FOLDER=/DZExams

MEGA_EMAIL_2=compte2@email.com
MEGA_PASSWORD_2=motdepasse2
MEGA_FOLDER_2=/DZExams_backup
Installation : pip install pycryptodome
ⓘ Numérotez avec _2, _3... pour plusieurs comptes (jusqu'à 5).

🟡 Comptes Google Drive — Sélectionnez le(s) compte(s)

Chargement...
Étapes :
1. console.cloud.google.com → créer projet → activer Google Drive API
2. Identifiants → OAuth 2.0 → Application bureau → télécharger JSON → renommer credentials.json
3. ⚠ Ajouter http://localhost:8080 aux URI de redirection autorisés
4. Placer credentials.json à côté de dzexams_server.py
GDRIVE_CREDENTIALS_FILE=credentials.json
GDRIVE_FOLDER_NAME=DZExams

GDRIVE_CREDENTIALS_FILE_2=credentials_2.json
GDRIVE_FOLDER_NAME_2=DZExams_2
Installation : pip install google-api-python-client google-auth-oauthlib

🔵 Comptes Dropbox — Sélectionnez le(s) compte(s)

Chargement...
Étapes :
1. dropbox.com/developers/apps → Create app → Scoped access → Full Dropbox
2. ⚠ Onglet Permissions → cocher files.content.write + files.content.read → Submit
3. Onglet Settings → Generated access token → Generate (après avoir coché les permissions !)
DROPBOX_ACCESS_TOKEN=sl.votre_token
DROPBOX_FOLDER=/DZExams

DROPBOX_ACCESS_TOKEN_2=sl.autre_token
DROPBOX_FOLDER_2=/DZExams_2
Installation : pip install dropbox
